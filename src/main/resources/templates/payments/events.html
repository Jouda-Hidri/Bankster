Outbox and event delivery

The event is written alongside the state change it describes, and a separate dispatcher moves it outward. That removes the distributed commit: state and announcement can no longer disagree, only be temporarily out of step — which is what eventual consistency means in practice.

Delivery is at-least-once, because a lost acknowledgement is indistinguishable from a lost delivery. Exactly-once processing is reconstructed at the consumer: each handler records the event ids it has applied and skips repeats.
